# えらんで小テスト
小学1年〜中学3年の算数・数学。学習内容を選び、問題と解答を作成します。

公開URL: https://zoemon-lab.github.io/math-quiz/

- 5・10・20・50・100問、印刷・PDF保存、教師による問題と解答の編集。
- 画面で解くモード。対応iPadではスクリブルで文字入力できます。実機Pencil認識は未検証です。
- 数値・式は端末内で確認。説明・作図・活動は解答例・先生と確認します。
- 学習指導要領の確認項目は授業に合わせて編集・確認してください。全到達度の自動評価ではありません。
- 選択・テスト・解答記録は使用中のブラウザーに保存。端末間の同期はありません。大切なテストはJSONにも保存してください。
- アプリからAI/APIに解答を送信しません。配信サービスGitHub Pagesのアクセス処理はGitHubのポリシーが適用されます。
- 依存ライブラリのライセンスはTHIRD-PARTY-LICENSES.txtを参照。
